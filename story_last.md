## 📖 What Are We Building and Why?

The entire ProGRESS system has been built. The database is set up. The agents run. The API works. GraphRAG works. Now comes the **final scientific question**:

> **Does coordination actually help?** Is MPAC (the full multi-agent coordination protocol) better than Ad-Hoc (uncoordinated writes)? Which specific part of MPAC is responsible for the improvement?

To answer this, we need to:
1. Run the **same CTI workload** through each of the five protocols.
2. Measure **five metrics** for each protocol.
3. Save the numbers to a JSON file.
4. Generate **bar charts** comparing the protocols visually.
5. Write a **research report** that draws conclusions from the data.

There are **five protocols** to compare:

| Protocol Name | Key | What it means |
|---|---|---|
| Ad-Hoc (Baseline) | `adhoc` | Uncoordinated. Each agent writes directly with no checks. |
| Full MPAC | `mpac` | Full coordination: peer consensus + semantic locks + conflict detection. |
| Ablation: No A2A Peers | `ablation_no_a2a` | MPAC but without peer-to-peer cross-checking. |
| Ablation: No Locks | `ablation_no_locks` | MPAC but without Redis distributed locks. |
| Ablation: Timestamp Only | `ablation_timestamp` | MPAC but arbitration is first-come-first-served by timestamp only. |

## 📐 The Five Metrics Explained

Before writing any code, understand what you are measuring:

### GIR — Graph Inconsistency Rate (lower is better)
How many conflict situations exist in the graph after all agents have written to it?

```
GIR = (Number of unresolved Conflict nodes in Neo4j / Total domain nodes written) × 100
```

**Example:** If 500 nodes were written and 50 Conflict nodes remain unresolved, GIR = 10%.  
Ad-Hoc will have a **high** GIR (lots of conflicts). MPAC should have a **low** GIR (conflicts detected and resolved).

---

### CR — Conflict Resolution Rate (higher is better)
Of all conflicts that were detected, what percentage were resolved (arbitrated)?

```
CR = (Conflict nodes with status = resolved / Total Conflict nodes) × 100
```

**Example:** If 50 conflicts were detected and MPAC resolved 45 of them, CR = 90%.

---

### CRA — Conflict Resolution Accuracy (higher is better)
Of the conflicts MPAC resolved, how often did it pick the correct winner? We compare against the **63 known ground-truth conflicts** in `data/analysis/conflicts.json`. The "correct" family is the one with the highest confidence score in the ground-truth record.

```
CRA = (Resolutions that matched ground-truth winner / Total conflicts resolved that have a ground-truth match) × 100
```

**Example:** 30 conflicts were resolved. 25 matched what ground-truth says is correct. CRA = 83.3%.

---

### PTC — Provenance Trail Completeness (higher is better)
Every node in the graph should have an unbroken trail back to: `DomainNode → Claim → Evidence → Principal`. PTC measures if this chain is intact.

```
PTC = (Domain nodes with a complete provenance chain / Total domain nodes) × 100
```

**Example:** If 500 nodes were written and 490 have a valid claim+evidence+principal chain, PTC = 98%.  
Ad-Hoc will have a **low** PTC because it writes directly without attaching provenance. MPAC attaches full provenance.

---

### Latency (lower is better)
Average and 95th-percentile time (in milliseconds) it takes for one `submit()` call to complete under each protocol.

```python
SOURCE_FILES = {

    "domain":     "Domain",

    "md5_hash":   "FileHash",

def _ioc_type_to_label(ioc_type: str | None) -> str:
    """Convert a raw ioc_type string into a Neo4j node label."""
    if ioc_type:
        for key, label in IOC_TYPE_TO_LABEL.items():
            if key in ioc_type.lower():
                return label
    return "Malware"


def _load_workload(size: int) -> list[dict[str, Any]]:
    """
    Load up to `size` records total, spread evenly across all four sources.
    Returns a list of dicts, each with keys: principal_id, ioc_value, ioc_type,
    malware_family, confidence.
    """
    per_source = max(1, size // len(PRINCIPALS))
    workload: list[dict[str, Any]] = []

    for principal, filepath in SOURCE_FILES.items():
        path = Path(filepath)
        if not path.exists():
            log.warning("Source file not found, skipping: %s", filepath)
            continue
        with open(path, encoding="utf-8") as fh:
            records = json.load(fh)
        # Take a slice and tag each record with its principal.
        for rec in records[:per_source]:
            workload.append({
                "principal_id":   principal,
                "ioc_value":      rec.get("ioc_value", ""),
                "ioc_type":       rec.get("ioc_type", ""),
                "malware_family": rec.get("malware_family", ""),
                "confidence":     rec.get("confidence", 50),
            })

    log.info("Workload loaded: %d records (requested %d)", len(workload), size)
    return workload


def _make_graph_operation(item: dict[str, Any]) -> GraphOperation:
    """Convert one workload record into a GraphOperation the coordinators accept."""
    label = _ioc_type_to_label(item["ioc_type"])
    # The lock_key ties the lock to the specific entity being written.
    lock_key = f"{label}:{item['ioc_value']}"
    props: dict[str, Any] = {
        "malware_family": item["malware_family"],
        "confidence":     item["confidence"],
        "source":         item["principal_id"],
    }
    return GraphOperation(
        operation_type=f"MERGE_{label.upper()}",
        lock_keys=[lock_key],
        node_label=label,
        node_key="value" if label != "FileHash" else "sha256",
        node_value=item["ioc_value"],
        properties=props,
        principal=item["principal_id"],
    )


def _make_coordinator(protocol: str, neo4j_client: Neo4jClient,
                      lock_manager: SemanticLockManager):
    """Return the right coordinator object for a given protocol string."""
    if protocol == "adhoc":
        return AdHocCoordinator(neo4j_client)
    if protocol == "mpac":
        return MPACCoordinator(neo4j_client, lock_manager)
    if protocol == "ablation_no_a2a":
        return MPACAblationCoordinator(neo4j_client, lock_manager, ablation_mode="no_a2a")
    if protocol == "ablation_no_locks":
        return MPACAblationCoordinator(neo4j_client, lock_manager, ablation_mode="no_locks")
    if protocol == "ablation_timestamp":
        return MPACAblationCoordinator(neo4j_client, lock_manager, ablation_mode="timestamp")
    raise ValueError(f"Unknown protocol: {protocol}")

# Neo4j wipe between runs
# ---------------------------------------------------------------------------

async def _wipe_domain_nodes(neo4j_client: Neo4jClient) -> None:
    """
    Delete ALL nodes and relationships from Neo4j, then re-initialize the schema.
    Called between each protocol run so each run starts from a clean slate.
    """
    log.info("Wiping Neo4j graph (DETACH DELETE all)...")
    async with neo4j_client.driver.session() as session:
        await session.run("MATCH (n) DETACH DELETE n")
    # Re-apply constraints and indexes after wipe.
    await neo4j_client.initialize_schema()
    log.info("Neo4j wiped and schema re-initialized.")


# ---------------------------------------------------------------------------
# Metric calculators
# ---------------------------------------------------------------------------

async def _compute_gir(neo4j_client: Neo4jClient, total_nodes: int) -> float:
    """
    GIR = (unresolved Conflict nodes / total domain nodes written) x 100.
    Queries Neo4j for Conflict nodes where status = 'unresolved'.
    Returns 0.0 if no nodes were written.
    """
    if total_nodes == 0:
        return 0.0
    async with neo4j_client.driver.session() as session:
        result = await session.run(
            "MATCH (c:Conflict {status: 'unresolved'}) RETURN count(c) AS cnt"
        )
        record = await result.single()
        unresolved = record["cnt"] if record else 0
    gir = (unresolved / total_nodes) * 100
    log.info("GIR: %d unresolved conflicts / %d nodes = %.2f%%", unresolved, total_nodes, gir)
    return round(gir, 2)


async def _compute_cr(neo4j_client: Neo4jClient) -> float:
    """
    CR = (resolved Conflict nodes / total Conflict nodes) x 100.
    Returns 0.0 if no conflicts exist (meaning nothing to resolve).
    """
    async with neo4j_client.driver.session() as session:
        total_res = await session.run("MATCH (c:Conflict) RETURN count(c) AS cnt")
        total_rec = await total_res.single()
        total = total_rec["cnt"] if total_rec else 0

        resolved_res = await session.run(
            "MATCH (c:Conflict {status: 'resolved'}) RETURN count(c) AS cnt"
        )
        resolved_rec = await resolved_res.single()
        resolved = resolved_rec["cnt"] if resolved_rec else 0

    if total == 0:
        return 0.0
    cr = (resolved / total) * 100
    log.info("CR: %d resolved / %d total = %.2f%%", resolved, total, cr)
    return round(cr, 2)


async def _compute_cra(neo4j_client: Neo4jClient) -> float:
    """
    CRA = (correct resolutions / total resolved that match ground truth) x 100.

    For each resolved Conflict node in Neo4j, we look up the same IOC in the
    ground-truth conflicts.json. If the protocol picked the same winning family
    as the highest-confidence source in ground-truth, it counts as correct.
    """
    # Load ground truth.
    if not CONFLICTS_GROUND_TRUTH_PATH.exists():
        log.warning("conflicts.json not found; CRA = 0")
        return 0.0

    with open(CONFLICTS_GROUND_TRUTH_PATH, encoding="utf-8") as fh:
        ground_truth_list: list[dict] = json.load(fh)

    # Build a lookup: ioc_value -> canonical winning family (highest confidence)
    # The ground-truth file lists conflicting families; the first listed family
    # from the source with the highest confidence is treated as "ground truth".
    gt_lookup: dict[str, str] = {}
    for item in ground_truth_list:
        ioc = item.get("ioc_value", "")
        # Pick the family with max confidence from involved_records.
        records = item.get("involved_records", [])
        if records:
            best = max(records, key=lambda r: r.get("confidence", 0))
            gt_lookup[ioc] = (best.get("malware_family") or "").lower()

    if not gt_lookup:
        return 0.0

    # Query resolved conflicts from Neo4j.
    async with neo4j_client.driver.session() as session:
        result = await session.run(
            """
            MATCH (c:Conflict {status: 'resolved'})
            RETURN c.ioc_value AS ioc_value,
                   c.winning_family AS winning_family
            """
        )
        records = await result.data()

    if not records:
        return 0.0

    matched = 0
    total_comparable = 0
    for rec in records:
        ioc = rec.get("ioc_value", "")
        winner = (rec.get("winning_family") or "").lower()
        if ioc in gt_lookup:
            total_comparable += 1
            if winner == gt_lookup[ioc]:
                matched += 1

    if total_comparable == 0:
        return 0.0
    cra = (matched / total_comparable) * 100
    log.info("CRA: %d correct / %d comparable = %.2f%%", matched, total_comparable, cra)
    return round(cra, 2)


async def _compute_ptc(neo4j_client: Neo4jClient) -> float:
    """
    PTC = (domain nodes with complete provenance chain / total domain nodes) x 100.

    A "complete provenance chain" means the domain node is reachable from at
    least one ProvenanceClaim node (which links the write back to a source
    and a principal). Ad-Hoc writes raw nodes with no claim attached, so
    its PTC will be near 0%.
    """
    async with neo4j_client.driver.session() as session:
        # Count domain nodes that have at least one claim linking to them.
        # Domain node labels: IP, Domain, URL, FileHash, Malware.
        with_provenance_res = await session.run(
            """
            MATCH (d)
            WHERE d:IP OR d:Domain OR d:URL OR d:FileHash OR d:Malware
            AND EXISTS {
                MATCH (pc:ProvenanceClaim)-[:ASSERTS]->(d)
                WHERE pc.accepted = true
            }
            RETURN count(d) AS cnt
            """
        )
        wp_rec = await with_provenance_res.single()
        with_provenance = wp_rec["cnt"] if wp_rec else 0

        total_res = await session.run(
            """
            MATCH (d)
            WHERE d:IP OR d:Domain OR d:URL OR d:FileHash OR d:Malware
            RETURN count(d) AS cnt
            """
        )
        total_rec = await total_res.single()
        total = total_rec["cnt"] if total_rec else 0

    if total == 0:
        return 0.0
    ptc = (with_provenance / total) * 100
    log.info("PTC: %d with provenance / %d total = %.2f%%", with_provenance, total, ptc)
    return round(ptc, 2)


def _compute_latency_stats(latency_samples: list[float]) -> dict[str, float]:
    """
    Given a list of per-operation latency values in milliseconds, compute:
    - mean_latency_ms
    - p95_latency_ms  (95th percentile - the slowest 5% are excluded)
    """
    if not latency_samples:
        return {"mean_latency_ms": 0.0, "p95_latency_ms": 0.0}
    arr = np.array(latency_samples, dtype=float)
    return {
        "mean_latency_ms": round(float(np.mean(arr)), 2),
        "p95_latency_ms":  round(float(np.percentile(arr, 95)), 2),
    }


# ---------------------------------------------------------------------------
# Single-protocol run
# ---------------------------------------------------------------------------

async def _run_one_protocol(
    protocol: str,
    workload: list[dict[str, Any]],
    neo4j_client: Neo4jClient,
    lock_manager: SemanticLockManager,
) -> dict[str, Any]:
    """
    Wipe the graph, then process the full workload under `protocol`.
    Returns a dict of raw metric data for this protocol.
    """
    log.info("=" * 60)
    log.info("Starting protocol run: %s  (%d records)", protocol, len(workload))

    # --- Fresh start ---
    await _wipe_domain_nodes(neo4j_client)

    coordinator = _make_coordinator(protocol, neo4j_client, lock_manager)

    latency_samples: list[float] = []
    operations_attempted = 0
    operations_committed = 0
    conflict_count = 0

    # Semaphore limits concurrency to CONCURRENCY_WORKERS parallel submit() calls.
    sem = asyncio.Semaphore(CONCURRENCY_WORKERS)

    async def _submit_one(item: dict[str, Any]) -> None:
        nonlocal operations_attempted, operations_committed, conflict_count
        op = _make_graph_operation(item)
        async with sem:
            result: CoordinationResult = await coordinator.submit(op)
        operations_attempted += 1
        operations_committed += result.operations_committed
        if result.conflict_detected:
            conflict_count += 1
        if result.latency_ms and result.latency_ms > 0:
            latency_samples.append(result.latency_ms)

    # Submit all workload items concurrently (bounded by semaphore).
    await asyncio.gather(*[_submit_one(item) for item in workload])

    log.info(
        "Protocol %s done: attempted=%d committed=%d conflicts_detected=%d",
        protocol, operations_attempted, operations_committed, conflict_count,
    )

    # --- Compute metrics from the graph state ---
    gir  = await _compute_gir(neo4j_client, operations_committed)
    cr   = await _compute_cr(neo4j_client)
    cra  = await _compute_cra(neo4j_client)
    ptc  = await _compute_ptc(neo4j_client)
    lat  = _compute_latency_stats(latency_samples)

    return {
        "protocol":             protocol,
        "workload_size":        len(workload),
        "operations_attempted": operations_attempted,
        "operations_committed": operations_committed,
        "conflicts_detected":   conflict_count,
        "GIR":                  gir,
        "CR":                   cr,
        "CRA":                  cra,
        "PTC":                  ptc,
        **lat,
    }


# ---------------------------------------------------------------------------
# Main entry point
# ---------------------------------------------------------------------------

class BenchmarkRunner:
    """
    Orchestrates a full head-to-head benchmark across all five protocols.

    Usage:
        runner = BenchmarkRunner(workload_size=200, protocols=ALL_PROTOCOLS)
        results = await runner.run()
    """

    def __init__(
        self,
        workload_size: int = WORKLOAD_SIZE,
        protocols: list[str] | None = None,
    ) -> None:
        self.workload_size = workload_size
        self.protocols = protocols if protocols is not None else ALL_PROTOCOLS

    async def run(self) -> list[dict[str, Any]]:
        """Run all protocols sequentially. Returns a list of per-protocol result dicts."""
        workload = _load_workload(self.workload_size)
        if not workload:
            raise RuntimeError("Workload is empty - check that data/normalized/*.json files exist.")

        neo4j_client = Neo4jClient()
        await neo4j_client.connect()
        lock_manager = SemanticLockManager()

        results: list[dict[str, Any]] = []
        try:
            for protocol in self.protocols:
                result = await _run_one_protocol(
                    protocol, workload, neo4j_client, lock_manager
                )
                results.append(result)
                log.info("Result for %s: %s", protocol, result)
        finally:
            await neo4j_client.close()

        # Save results to disk.
        RESULTS_PATH.parent.mkdir(parents=True, exist_ok=True)
        with open(RESULTS_PATH, "w", encoding="utf-8") as fh:
            json.dump(results, fh, indent=2)
        log.info("Results saved to %s", RESULTS_PATH)

        return results


async def _main() -> None:
    runner = BenchmarkRunner(workload_size=WORKLOAD_SIZE, protocols=ALL_PROTOCOLS)
    results = await runner.run()
    print("\n\n=== BENCHMARK COMPLETE ===")
    print(f"Results saved to: {RESULTS_PATH}\n")
    header = f"{'Protocol':<25} {'GIR':>6} {'CR':>6} {'CRA':>6} {'PTC':>6} {'Mean ms':>9} {'p95 ms':>9}"
    print(header)
    print("-" * len(header))
    for r in results:
        print(
            f"{r['protocol']:<25} "
            f"{r['GIR']:>6.1f} "
            f"{r['CR']:>6.1f} "
            f"{r['CRA']:>6.1f} "
            f"{r['PTC']:>6.1f} "
            f"{r['mean_latency_ms']:>9.1f} "
            f"{r['p95_latency_ms']:>9.1f}"
        )


if __name__ == "__main__":
    asyncio.run(_main())
```

```python
"""
benchmark/visualizer.py
-----------------------
STORY-014: Results Analysis, Visualization & Research Report Generator.

Loads benchmark_results.json and produces:
  1. data/results/comparison_table.md   - Markdown comparison table
  2. data/results/charts/gir.png        - GIR bar chart

Usage (run from project root):

from __future__ import annotations

import json
from pathlib import Path

import matplotlib

import matplotlib.pyplot as plt

RESULTS_PATH = Path("data/results/benchmark_results.json")
CHARTS_DIR   = Path("data/results/charts")
TABLE_PATH   = Path("data/results/comparison_table.md")

# Human-readable labels for the five protocols.
PROTOCOL_LABELS = {
    "adhoc":              "Ad-Hoc\n(Baseline)",
    "mpac":               "Full MPAC",

    "ablation_no_locks":  "Ablation\nNo Locks",

}


def load_results() -> list[dict]:
    if not RESULTS_PATH.exists():
        raise FileNotFoundError(
            f"{RESULTS_PATH} not found. "

        )

def _bar_chart(
    results: list[dict],
    metric_key: str,
    title: str,
    ylabel: str,
    output_path: Path,
    lower_is_better: bool = False,
) -> None:
    """Draw a bar chart for one metric across all protocols and save as PNG."""
    protocols = [r["protocol"] for r in results]
    values    = [r.get(metric_key, 0.0) for r in results]
    colors    = [PROTOCOL_COLORS.get(p, "#95a5a6") for p in protocols]
    labels    = [PROTOCOL_LABELS.get(p, p) for p in protocols]

    fig, ax = plt.subplots(figsize=(10, 6))
    bars = ax.bar(labels, values, color=colors, edgecolor="black", linewidth=0.8)

    # Annotate each bar with its value.
    for bar, val in zip(bars, values):
        ax.text(
            bar.get_x() + bar.get_width() / 2.0,
            bar.get_height() + 0.5,
            f"{val:.1f}",
            ha="center", va="bottom", fontsize=11, fontweight="bold",
        )

    direction = "lower is better" if lower_is_better else "higher is better"
    ax.set_title(f"{title}  ({direction})", fontsize=14, fontweight="bold", pad=15)
    ax.set_ylabel(ylabel, fontsize=12)
    ax.set_xlabel("Protocol", fontsize=12)
    ax.set_ylim(0, max(values) * 1.25 if max(values) > 0 else 10)
    ax.grid(axis="y", linestyle="--", alpha=0.5)
    fig.tight_layout()

    output_path.parent.mkdir(parents=True, exist_ok=True)
    fig.savefig(output_path, dpi=150)
    plt.close(fig)
    print(f"Chart saved: {output_path}")


def generate_charts(results: list[dict]) -> None:
    """Generate all five metric bar charts."""
    CHARTS_DIR.mkdir(parents=True, exist_ok=True)

    _bar_chart(results, "GIR",             "Graph Inconsistency Rate (GIR)",
               "GIR (%)", CHARTS_DIR / "gir.png", lower_is_better=True)

    _bar_chart(results, "CR",              "Conflict Resolution Rate (CR)",
               "CR (%)", CHARTS_DIR / "cr.png", lower_is_better=False)

    _bar_chart(results, "CRA",             "Conflict Resolution Accuracy (CRA)",
               "CRA (%)", CHARTS_DIR / "cra.png", lower_is_better=False)

    _bar_chart(results, "PTC",             "Provenance Trail Completeness (PTC)",
               "PTC (%)", CHARTS_DIR / "ptc.png", lower_is_better=False)

    _bar_chart(results, "mean_latency_ms", "Mean Commit Latency",
               "Latency (ms)", CHARTS_DIR / "latency.png", lower_is_better=True)


def generate_comparison_table(results: list[dict]) -> None:
    """Write a Markdown comparison table to data/results/comparison_table.md."""
    lines = [
        "# ProGRESS Benchmark: Protocol Comparison Table\n",
        "| Protocol | GIR (%) lower-is-better | CR (%) higher-is-better | CRA (%) higher-is-better | PTC (%) higher-is-better | Mean Latency (ms) lower-is-better | p95 Latency (ms) lower-is-better |",
        "|---|---|---|---|---|---|---|",
    ]
    for r in results:
        label = PROTOCOL_LABELS.get(r["protocol"], r["protocol"]).replace("\n", " ")
        lines.append(
            f"| {label} "
            f"| {r.get('GIR', 0):.1f} "
            f"| {r.get('CR', 0):.1f} "
            f"| {r.get('CRA', 0):.1f} "
            f"| {r.get('PTC', 0):.1f} "
            f"| {r.get('mean_latency_ms', 0):.1f} "
            f"| {r.get('p95_latency_ms', 0):.1f} |"
        )

    TABLE_PATH.parent.mkdir(parents=True, exist_ok=True)
    with open(TABLE_PATH, "w", encoding="utf-8") as fh:
        fh.write("\n".join(lines) + "\n")
    print(f"Comparison table saved: {TABLE_PATH}")


def find_worst_ablation(results: list[dict]) -> str:
    """
    Returns the ablation mode that degraded GIR the most compared to full MPAC.
    (Highest GIR among the three ablation modes = worst degradation.)
    """
    ablation_protocols = [r for r in results if r["protocol"].startswith("ablation")]
    if not ablation_protocols:
        return "N/A"
    worst = max(ablation_protocols, key=lambda r: r.get("GIR", 0))
    return worst["protocol"]
```
